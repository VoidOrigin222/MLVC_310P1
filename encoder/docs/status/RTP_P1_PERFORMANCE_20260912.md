# RTP 双机性能实测（2026-09-12）

测试设备：

- 编码端：`ascend-lab`，Ascend 310P1
- 解码端：`decode-310p1`，Ascend 310P1
- 传输：RTP，MLVC v1
- 每秒调用一次 `npu-smi info -t usages -i 0 -c 0`

## 结果

| 分辨率 | 编码帧数 | 编码 FPS | 解码帧数 | 解码 FPS | 编码 AICore 实际计算平均/峰值 | 解码 AICore 实际计算平均/峰值 |
|---|---:|---:|---:|---:|---:|---:|
| 720P | 537 | 84.89 | 537 | 80.83 | 56.75% / 58% | 57.75% / 58% |
| 1080P | 537 | 33.54 | 537 | 31.89 | 64.30% / 66% | 63.09% / 65% |

两组测试编码端和解码端均报告 `encode=ok`、`decode=ok`，无帧丢失或 RTP 重组错误。

NPU 的“实际计算平均值”仅统计 AICore 大于 0 的采样点；解码器启动后等待编码端发送首个 RTP 包期间的 0% 样本单独排除。若按整个监控窗口计算，720P 编码/解码平均值为 32.43%/8.88%，1080P 为 49.46%/22.39%。
